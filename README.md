# R for Molecular Biology

This is a collection of R scripts I developed during my PhD for my Thesis.

Each folder contains all necessary data to test run the scripts, along with a README file with further instructions. For each script, some parameters must be corrected to fit specifically your data, others like the colors of the plots can be adapted to your personal taste. Promise I will complement this page with video tutorials in a non so distant future. For the moment, seach the scrips to find the one you need for your analyses.
